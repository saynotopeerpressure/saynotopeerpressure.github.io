# Cookie's Academic World

An interactive Japanese Minecraft-inspired academic homepage for `saynotopeerpressure.github.io`.

## Local Development

```bash
npm install
npm run dev
```

## Deployment

Create a GitHub repository named `saynotopeerpressure.github.io`, push this project to `main`, and GitHub Pages will publish the `dist` build through the included workflow.

## Editing Content

Most page content lives in `src/data/profile.js`. Update that file when projects, papers, links, or contact details change.
